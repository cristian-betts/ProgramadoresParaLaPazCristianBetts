Pregunta: ¿Por qué es importante que los proyectos de software mantengan un registro de cambios usando herramientas como Git?

Respuesta: Mantener un registro de cambios en un proyecto de software es importante porque permite conocer qué modificaciones se han realizado a lo largo del desarrollo. Herramientas como Git facilitan el seguimiento de cada cambio, indicando quién lo realizó y cuándo se hizo. Esto ayuda a identificar errores y recuperar versiones anteriores si surge algún problema. Además, mejora la organización del proyecto y evita la pérdida de información importante. En equipos de trabajo, Git permite que varias personas colaboren de manera ordenada sobre el mismo código. También facilita la revisión de cambios antes de incorporarlos al proyecto principal. Gracias a este control, el desarrollo es más seguro, eficiente y transparente. Por estas razones, Git se ha convertido en una herramienta fundamental en la ingeniería de software.
